# webodv ENSO Tutoria

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23090181.svg)](https://doi.org/10.5281/zenodo.23090181)

Step-by-step tutorials on webODV's ENSO monitoring.

In this example we show how to use webODV's data exchange functionality -
the ability to store reference data and apply it to current data.

We provide two use cases, [Surface.md](Surface.md) and [Section.md](Section.md).
